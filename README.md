# Whale Tavern V2 — 无需部署服务器的 WebRTC 手动连接版

## 运行

解压后打开 `index.html`。单人模式无需网络；3D 场景使用 CDN 的 Three.js，需要互联网。WebRTC 在部分浏览器的 `file://` 页面上可能受到安全上下文限制，推荐通过 GitHub Pages / 静态网页托管（仅上传静态文件，无需配置或运行服务器）打开同一网页。**不需要运行 Python，不需要 Node.js，也不需要开端口。**

## iPad / Mac 联机（每个玩家重复一次）

1. 房主在网页输入昵称，点击「创建 P2P 房间」，然后「邀请玩家」。
2. 房主复制生成的邀请码，通过消息发给玩家。
3. 玩家打开同一个网页，点击「加入朋友的房间」，粘贴邀请码并点击「确认连接信息」。
4. 玩家复制生成的回复码发回房主。
5. 房主粘贴回复码并点击「确认连接信息」。等待显示连接成功。然后房主可以继续邀请其他玩家、添加 AI，点击开始。

连接码包含 ICE 网络候选地址，不要公开发布；只与信任的朋友交换。浏览器可能需要 1–9 秒收集候选。需要公共 STUN 服务器，部分 NAT / 防火墙环境下可能无法连接；没有 TURN 中继，无法保证跨网络成功。iPad 锁屏、浏览器切后台可能断开房间。房主退出后游戏不能继续。请保持页面前台。

## 当前限制

- 这是 P2P 原型，不包含断线恢复、房主迁移、反作弊或公网 TURN。
- 只支持最多四名玩家；房主权威计算手牌与游戏规则，客户端不会接收他人的手牌。
- 3D 场景为简化原创几何角色，并非商业级人物动画。
- 规则：每轮 5 张手牌，目标牌 A/K/Q，J 通配；每次出 1–3 张；下一位可质疑；惩罚为游戏内随机淘汰。
