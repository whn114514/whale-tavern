# Whale Crash V1.0
原创 2D 车辆物理对战小游戏，适用于 iPad Safari / Mac 浏览器。

## 运行
直接打开 index.html，或将文件上传到 GitHub Pages 仓库的 `crash/index.html`，访问 `https://用户名.github.io/仓库名/crash/`。

## 功能
- 8 种车辆可选择，各有不同重量、加速、尺寸
- 单人对 AI、头部碰撞判分、先到 5 分获胜
- iPad 触屏按键 / Mac 键盘 A D W 或方向键
- 完全静态网页，不需要服务器，不需要外部 CDN

## 当前限制
- V1.0 为单人 AI 模式；尚无多人 WebRTC 联机
- 物理系统为简化街机模拟，不是完整刚体物理引擎
